# 천안시 도시공원 — 인터랙티브 웹 프레젠테이션

## 실행
`index.html` 파일을 브라우저로 열면 실행됩니다. 별도 서버나 DB가 필요하지 않습니다.

## GitHub Pages
1. ZIP 압축 해제 후 `index.html`, `styles.css`, `script.js`, `slides.json`, `favicon.svg`, `assets/` 전체를 GitHub 저장소 최상위에 업로드합니다.
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
3. 생성된 주소로 접근합니다.

## 조작
- 상단 내비게이션 / 하단 점 / 이전·다음 버튼 / 좌우 방향키 / 모바일 좌우 스와이프
- 전체 슬라이드 인덱스 (▦)
- 원본 PPT 텍스트 전체 보기 (☷, 상세 내용)
- 전체화면 (⛶), 5.5초 자동재생

## 출처 및 자료 유의사항
- 사용자가 제공한 `천안시_도시공원_편집가능_재저장_검증본.pptx` 10장에 근거함.
- 원본 화면은 4:3 비율로 무손실 구성 유지한 고화질 WebP 이미지로 표시함.
- 원본 내 이미지에는 '설명용 연출 이미지(실제 현장 사진 아님)' 표기가 포함됨.
- 일부 지표는 2021년 기준이며, 원본의 미래 제안은 확정 정책이 아님.
- 원본 디자인을 정확히 보존하기 위해 차트/인포그래픽은 슬라이드 고화질 화면에 포함되며, 도표 요소 자체가 개별 웹 컴포넌트로 편집되지는 않습니다.
- 모든 리소스 상대 경로 사용. 외부 CDN 없음.
